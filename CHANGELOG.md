## [Unreleased]

### Added

- G0 core: installable package with strict intake types and eight
  public protocol views.
- Bounded canonical JSON codecs for all specification types.
- Immutable content-addressed artifact repository with memory and
  transactional SQLite backends.
- Append-only lifecycle reducer with specified-head replay.
- Atomic terminal and cross-run transaction support.
- Provenance catalog covering 17 isolated runtime profiles.
- CLI skeleton accepting typed requests and returning JSON views.
- Provenance verification command (`automarkov verify-provenance`).
- Runtime policy documents for LLM, Tavily, PyTorch/RLlib,
  SwanLab, and research repo boundaries.
- Repository safety documentation and `.env.example` template.
