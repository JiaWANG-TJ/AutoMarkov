## Research Question
How can homogeneous or heterogeneous agents learn to cooperate and compete in simple physics-based environments with continuous observation and action spaces?

## Algorithm Summary
MPE2 (Multi-Agent Particle Environments) provides a set of 2D particle-world scenarios with communication channels. Agents observe local information (positions, velocities, landmarks, entity states) and can send continuous communication messages. The environments span cooperative navigation, physical deception, predator-prey, and communication-based tasks. Centralized training with decentralized execution (MADDPG-style) is the standard training paradigm.

## AutoMarkov Mapping
- Particle physics simulation maps to environment step dynamics in `generation_methods.py`.
- Continuous communication channels relate to agent message passing in multi-agent rollouts.
- Physical reward shaping connects to team-level metrics in `statistics.py`.

## Benchmarks
- Cooperative communication (physical deception)
- Predator-prey pursuit
- Cooperative navigation with reference

## Limitations
- Simple 2D physics; does not capture complex spatial reasoning.
- Communication channel is unstructured; emergent language is hard to interpret.
- Limited scalability to large agent populations.
