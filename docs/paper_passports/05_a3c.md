## Research Question
Can asynchronous parallel actor-learners replace experience replay for stable deep RL training?

## Algorithm Summary
A3C (Asynchronous Advantage Actor-Critic) runs multiple parallel agents each with its own copy of the environment and network. Each agent computes gradients independently and asynchronously updates a shared global network. The advantage function (GAE-based) reduces variance in policy gradient estimates. An entropy bonus term encourages exploration. The asynchronous framework eliminates the need for experience replay.

## AutoMarkov Mapping
- Parallel rollout generation connects to batched `generation_methods.py`.
- Shared global network update corresponds to distributed training in `rllib_training.py`.
- Entropy bonus term relates to exploration incentives in policy generation.

## Benchmarks
- Atari 2600 games (discrete)
- MuJoCo continuous control (continuous variant A2C)
- TORCS racing simulator

## Limitations
- On-policy with high variance per worker.
- Hyperparameter sensitivity to number of parallel workers.
- Hard to scale efficiently on a single GPU due to asynchronous nature.
